# Evidence pack, from committed material only

Generated by `npm run evidence:pack` from the receipts in `data/jobs` and the call logs in `evidence/`. Generating this pack makes no new model calls; it reads committed call logs. No museum-image fetch is logged in `evidence/`, and no museum image is in this pack. A test checks this file is current.

## Receipts

- 42 jobs, 43 renders; 42 of 42 hash chains verify (one chain per job; fixture-shirt-01 has more than one render).
- Garments with receipts: kurta-01, kurta-02, shirt-plaid, shirt-zebra.
- Gate decisions per render: REFUSE 18, RELEASE 15, REVIEW 10. Live renders (37): REFUSE 17, RELEASE 10, REVIEW 10. Fixture renders (6): REFUSE 1, RELEASE 5. Renders with no usable verifier answer (gate REFUSE not_verified): 6 (VerifierProtocolError 2, VerifierTransportError 4). These are renders, not calls: a VerifierTransportError is a call counted as Failed in the table below, a VerifierProtocolError is a call that answered but whose output was not JSON.
- One row per render, with providers, model ids and tokens: `results.csv`.

## Verify a receipt offline

Open `web/verify.html` from disk or served over local HTTP (both checked: over HTTP in Chromium, from disk in headless Edge by the demo capture). It makes no network request: its Content-Security-Policy blocks every request. Give it a job's `receipt.jsonl` and its released image: it says VALID. Change one byte of the receipt and give it again: it says TAMPERED. `test/check.test.ts` runs the same check in Node with the same `src/core.js`.

## Muse Spark cross-check (MS4)

68 pairs, 204 of 204 runs answered. Same garment: 24 of 30 released. Wrong garment: 153 of 153 refused. Changed by a try-on: 17 of 21 held. Same decision on all 3 runs: 65 of 68 pairs.

## Calibration at the shipped thresholds

18 same and 19 different recorded renders, 37 in all, in three groups that add up: 29 judged as their label says (10 same released + 19 different held), 4 false refusals and 4 same-garment renders sent to REVIEW: 29 + 4 + 4 = 37. 0 false matches. The 6 unmeasured renders are inside those groups, not added to them (2 judged as labelled, 1 false refusal, 3 REVIEW). Source: `evidence/calibration-jobs-2026-10-29.json`.

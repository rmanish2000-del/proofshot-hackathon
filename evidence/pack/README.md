## Verify a receipt offline

Open `web/verify.html` from disk (no server, no network: its Content-Security-Policy blocks every request). Give it a job's `receipt.jsonl` and its released image: it says VALID. Change one byte of the receipt and give it again: it says TAMPERED. `test/check.test.ts` runs the same check in Node with the same `src/core.js`.

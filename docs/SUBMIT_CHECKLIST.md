# Submit checklist (Cerebral Valley form)

For the person filling in the form, and for a judge who wants to know where a
form answer came from. Each field names the file and section its text is
pasted from; nothing here is new text. Numbers with a figure marker are
generated by `npm run figures` (this file is in `FIGURE_DOCS`, so a test fails
if they drift). Anything not provable from this repository says UNVERIFIED or
pending.
